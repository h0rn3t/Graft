Usage: graft routes [options] [dir]

HTTP routes declared in the code and their handlers, under their Go route-group,
NestJS controller or Spring class prefix: Go net/http, gin, echo, chi and Fiber;
Flask, FastAPI and Django; Express and NestJS; Spring ($0, no LLM)

Arguments:
  dir           repository root (default: nearest ancestor with a graft/ index)

Options:
  --in <path>   narrow to nodes at or under this path prefix
  --json        output as JSON
  --no-refresh  skip the freshness check — answer from the graph as-is
  -h, --help    display help for command
