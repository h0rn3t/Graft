Usage: graft brain push [options] [dir]

Read THIS repo on your machine and build its brain — no GitHub App, works on
private repos

Arguments:
  dir           target repo directory (default: ".")

Options:
  --no-approve  leave the mined rules as drafts for review
  --no-watch    return as soon as the push is sent, without following the build
  -h, --help    display help for command
